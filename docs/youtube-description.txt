The audited control surface for a live multi-agent prediction-market platform.

TradeWizard is live: fourteen AI agents, a deterministic analysis pipeline, an autonomous Portfolio Manager, on-chain billing, support, and a newsletter. Warden is the separate internal product built to operate it safely.

New to prediction markets? A market is an exchange on a yes/no question. Shares cost 0-100 cents and pay $1 if correct, so the price reads as the crowd's probability. TradeWizard runs on Polymarket, sells analyses for credits, and can trade a customer's budget autonomously inside limits they approve.

Warden is not a CRUD dashboard. It is a role-gated control plane with its own Next.js app, API, Cognito identity, hash-chained audit trail, runtime settings, and deployment. It never holds wallet keys, signs transactions, or calls the CLOB.

Ask Warden is a read-only AI copilot. It answers incident, support, analysis, session, and risk questions with citations to the exact record, and every suggestion is a link, never an action.

Submitted to Kiroween 2026 (Frankenstein category): Next.js, Cognito, API Gateway, Lambda, RDS PostgreSQL, DynamoDB, S3, EventBridge, SNS, CloudWatch, Amplify, a conservative PWA, and four Kiro specs.

AUTHENTICATION AND AUTHORIZATION
- Separate Cognito admin client: email + password + TOTP
- Self-service MFA enrolment with a QR code
- Four cumulative roles: analyst, support, admin, owner
- Authorizer reads live Cognito groups, not the token snapshot
- Warden-only +warden aliases, and role-carrying invite links with expiry and use caps

HASH-CHAINED AUDIT
- Audit row written before the side effect
- Actor, action, target, reason, before/after state, request id, IP, user agent
- prev_hash plus row_hash chain every row to its predecessor
- completion_hash makes a flipped status detectable
- Verify names the first broken row; triggers reject updates and deletes
- Pending rows make a crash visible instead of silent

OPERATIONAL CONTROLS
- Fail-closed per-user kill switch: synchronous halt, asynchronous exit
- Session pause, resume, terminate
- Credits, plan overrides, account status, support notes
- Analysis cache invalidation, refunds, market requeue
- Runtime settings, each with a named consumer

ASK WARDEN (READ-ONLY)
- Incident, support, analysis, session, and risk questions
- Deterministic retrieval; one tool-less model call
- Every claim cites the exact record; answers are role-scoped
- Suggestions are links, never executions; no mutation route
- copilot_enabled kill switch and a per-operator daily cap
